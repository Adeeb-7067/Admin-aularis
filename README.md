# Auralis Admin

Listen Wise platform administration console built with TanStack Start, React, and Tailwind CSS.

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:8080

## Build

```bash
npm run build
npm run preview
```

## Deploy

- **Netlify**: uses `netlify.toml`
- **Vercel**: uses `vercel.json`
